# household-finance

A personal, self-hosted budgeting tool for one household.

- Runs on a Raspberry Pi on a home network; not a public service, no other users.
- Reads the owner's own bank and credit-card transactions and balances (read-only) to track monthly spending against a budget.
- Plaid is used for read-only access (Transactions, Balance) to the owner's own accounts at Canadian institutions. No payments, no money movement, no third-party data.
- Data stays on the owner's own hardware; nothing is shared or sold.
